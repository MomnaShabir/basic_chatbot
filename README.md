# Python Chatbot

A simple interactive chatbot built with Python that responds to user messages based on predefined rules.

### Features
- Takes user input and displays responses.
- Uses conditional statements to identify user messages.
- Provides predefined replies to common questions.
- Supports basic conversational interaction.

### Technologies Used
- Python
- Conditional Statements
- Loops
- Functions

### How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python chatbot.py
```

This project helped me practice Python fundamentals and understand the basics of building interactive applications.
